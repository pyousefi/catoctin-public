- The admin ZIP contained the unchanged original bytes.

- Hiding the original returned 404 to the family session while the admin could still download it (200).

The run exposed and resolved a missing CSP allowance for the installed Blob SDK's `https://vercel.com/api/blob/` control-plane endpoint. The new network-policy regression test protects that allowance without permitting arbitrary origins.

A scan of `.next/static` after the server-only album change found **zero actual family album URLs** in public JavaScript. Browser fixtures now use synthetic links. Historical Git commits still contain the original links; the repository is now private.

## Logout fix and expanded UI verification

The reported logout failure was reproduced in a real browser on the prior preview: the native POST sent `Origin: null`, returned 403, and retained the session. Both new family/admin logout regressions failed with 403 before the fix. `Referrer-Policy: same-origin` permits internal native POSTs while withholding referrers from external destinations; the strict Origin check remains unchanged. Local Next.js and Playwright now consistently use localhost.

The expanded suite passes **24 desktop/mobile Chromium checks** and **53 unit/integration tests**, plus formatting, TypeScript, and production build. Added UI journeys cover both logout roles, session removal, foreign/opaque-origin rejection, unavailable-storage login, empty photos, the 50-photo limit, and retry preserving year/contributor. CI retains failure screenshots and traces. Independent review found no concrete merge blocker.

## Release authorization and controls

The owner explicitly requested the additional UI coverage, merge, and production release. The repository is private; GitHub environments contain project/team identifiers and inherit the supplied repository-level `VERCEL_TOKEN`. The current private-repository plan leaves `main` unprotected and `prod.protection_rules` empty. Production promotion therefore remains the explicit, owner-authorized publication of a stable GitHub release rather than an enforced GitHub environment approval.

See the PR, GitHub Actions runs, and tagged release for final CI and deployment outcomes. These local preview checks used the authenticated Vercel CLI and do not independently establish the CI token's permissions.

## Boundaries

Actual iPhone/Android HEIC behavior, the organizer's manual Google album transfer, backup/restore procedures, and spending alerts still require verification. Mobile Chromium emulation is not iOS Safari. The retry regression checks preservation of metadata after a failed attempt, not eventual completion after a real network interruption. Production deployment and smoke results belong to the release record.
