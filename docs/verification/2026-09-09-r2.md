# R2 migration verification — 2026-09-09

Tracked in [issue #19](https://github.com/pyousefi/catoctin/issues/19).

## Verified

- Cloudflare's authenticated API confirms that bucket `catoctin` exists in the requested account, its managed public domain is disabled, and it has no public custom domains.
- The configured CORS policy allows signed upload-part `PUT` requests only. It does not enable public reads. Read-back of the policy matches [the documented configuration](../operations/r2-migration.md).
- Anonymous access to the managed R2 URL returns 401. A real original from the existing local/preview private Vercel Blob store returns 403 when fetched without credentials. No photo paths, credentials, or shared-album links were included in the verification output.
- `npm run typecheck`, `npm test`, `npm run build`, `npm run format:check`, and `git diff --check` pass. Unit/integration coverage includes actual PostgreSQL constraints through PGlite, exact-byte multipart transfer, signed part lengths, ownership, capacity, completion/cancellation races, deletion retry, migration hashes, concurrent migration/deletion cleanup, and reconciliation.
- The local Playwright run passes all 51 desktop/mobile/Android Chromium cases. The new multipart scenario transfers two parts, compares SHA-256 with its original, and retries save confirmation without retransferring bytes.
- Independent review identified cancellation/completion, deletion/migration, and abandoned-copy races. Each was fixed with regression coverage and reviewed again with no remaining actionable findings.
